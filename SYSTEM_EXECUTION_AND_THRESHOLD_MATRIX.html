2. Step-by-Step Execution Guide

A. Running the Python Sensor Bridge Server (`sensor_server.py`)

The bridge server exposes a RESTful API at port 5000. It automatically detects whether physical I2C sensors are connected and seamlessly falls back to testing simulation mode on non-hardware platforms.

  1. Install Dependencies:
    pip install flask flask-cors # If running on Raspberry Pi with physical I2C sensors: pip install smbus2
  2. Launch the Server:
    cd neuroband_server python sensor_server.py
    The terminal will output:
    ================================================================= NEUROBAND AI - ULTRA PRECISION SENSOR SERVER Listening on http://0.0.0.0:5000 REST API Endpoint: http://<IP_ADDRESS>:5000/api/biometrics Simulation Test: http://<IP_ADDRESS>:5000/api/simulate?hr=115 =================================================================
  3. Browser Dashboard Verification & Quick Threshold Simulation:
    Open http://localhost:5000 in any web browser. Use the quick buttons to simulate threshold events:
    • /api/simulate?hr=72&gyro=1.2&spo2=98 (Normal Baseline)
    • /api/simulate?hr=118 (High Pulse Tachycardia Warning)
    • /api/simulate?hr=48 (Low Pulse Bradycardia Warning)
    • /api/simulate?gyro=68 (Tremor & Kinematics Spike)
    • /api/simulate?spo2=89 (Low SpO2 Hypoxemia Emergency)

B. Running the Android Application in Android Studio

  1. Open Android Studio and select Open ➔ Choose the project folder Neuroband-AI.
  2. Allow Gradle to sync automatically.
  3. Select an active device (Physical Android Phone or Android Emulator API 26+).
  4. Click the green Run ('app') button (or press Shift + F10).
  5. Once launched, tap the Settings icon (4th tab on bottom bar):
    • If using Android Emulator and server is on the same PC: enter host 10.0.2.2.
    • If using Physical Phone: enter the local Wi-Fi IP of your computer or Raspberry Pi (e.g. 192.168.1.50).
    • Tap SAVE HOST and tap TEST LINK. The indicator will switch to ONLINE 🟢.

C. Switching Light & Dark Themes

The user interface supports both high-contrast Clean Light Theme and Deep Cyber Navy Dark Theme:

  • Open the Settings tab ➔ In the top "APPEARANCE & THEME" card, toggle the switch.
  • Clean Light Theme: Pristine slate-white surfaces, vibrant cyan & purple accents, and high-contrast dark text designed for bright environments.
  • Dark Cyber Theme: Deep navy OLED background with glowing cybernetic indicators.

D. Testing Haptic Vibration & Remedies

To verify the physical vibration actuator and on-screen remedy alert:

  • Navigate to Settings ➔ Under CONSOLE & ALERTS PREFERENCES, ensure "Tactile Vibration Guidance" is enabled.
  • Tap the "TEST VIBRATION & REMEDY WARNING" button.
  • The phone will vibrate with the warning haptic pattern, switch to the Home tab, and display the alert banner with the clinical remedy.

4. Explainable AI (SHAP / XAI) Interpretation

In NeuroBand AI, alerts are not opaque labels. Predictions are decomposed into additive feature contributions using SHAP (SHapley Additive exPlanations):

SHAP Additive Attribution Formula:
f(x) = E[f(x)] + ΦHeartRate + ΦSpO2 + ΦTremor + ΦTemperature + ΦGSR
  • Base Value E[f(x)] = 0.05: The expected baseline risk score when all sensors are inside Level 2 (Normal).
  • Negative Contribution (Φi ≤ 0): When a vital is in the normal range, its SHAP score suppresses false alerts ("Pulse is optimal, reducing overall risk").
  • Positive Contribution (Φi > 0): When a sensor deviates above or below threshold, its SHAP value increases proportionally, explicitly highlighting the exact biometric responsible for the warning to the clinician and patient.
